# 📝 更新日志 (Changelog)

**版本：** `v2.0.0`
**日期：** 2026-04-03
**状态：** 核心功能重构已完成

---

### 🚀 重大更新 (Major Overheads)
* **由静态目录转向动态路径导航 (Dynamic Path Navigation)**
    * 取消了硬编码的单级目录限制，引入 **`BASE_DIR`** 根目录概念。
    * 实现了基于 `context.user_data` 的实时路径状态维护，支持用户在 VPS 目录下进行无限深度的文件夹穿梭。
* **交互式文件系统浏览器 (Interactive File Browser)**
    * 新增 **文件夹探测逻辑**：自动识别子目录并冠以 📁 标识，置于文件列表顶部，符合主流文件管理器操作逻辑。
    * 新增 **层级回溯功能**：引入“⬆️ 返回上一级目录”动态按钮，支持在非根目录下向上平滑回退。

### ✨ 功能优化 (Feature Enhancements)
* **上下文感知的工作流 (Context-Aware Workflow)**
    * **合并任务 (Concat)**：优化了临时文件 `.txt` 队列及合并产物的生成路径。系统现在会自动在“当前操作目录”下执行 I/O 操作，避免了跨目录合并导致的路径溢出错误。
    * **转码任务 (Convert)**：转码后的 `.mp4` 文件将直接存储在源文件所在目录，实现了更科学的就近管理原则。
* **UI/UX 交互升级**
    * **智能路径缩写**：在菜单标题中引入路径映射机制，将冗长的系统路径映射为直观的 `🏠 根目录` 标识，提升移动端屏幕利用率。
    * **自动清理机制**：切换目录或返回上一级时，系统将自动重置当前的选择状态（Select Set），防止跨目录误操作导致的逻辑冲突。

### 🛠️ 技术改进 (Technical Refinement)
* **异步任务分发优化**：所有的 Action 逻辑均通过 `asyncio.create_task` 挂载，确保目录切换等 UI 操作不会被重量级的 FFmpeg 任务阻塞。
* **错误边界处理**：增加了对不存在目录或空目录的边界检测，并在 UI 层级提供友好的弹窗警告。

---

> **💡 部署提示：**
> 请确保您的 `BASE_DIR` 路径权限已配置正确（建议 `755` 权限），以便 Bot 能够正常读取下级子文件夹。如需中断任务，请随时使用 `/stop` 指令。
