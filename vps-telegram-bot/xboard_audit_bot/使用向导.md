## **推荐使用一键脚本**

```bash
curl -sS -O https://raw.githubusercontent.com/TAOYAO2233/vps/refs/heads/main/vps-telegram-bot/xboard_audit_bot/xboard_audit.sh && chmod +x xboard_audit.sh && ./xboard_audit.sh
```

## 📊 部署完毕后的常用运维命令（在主控机上使用）

部署完成后，一键脚本会将服务常驻后台。后续如果需要查看或管理，直接在主控机上执行以下命令：  
实时查看两台 VPS 的网络访问动态:

```bash
journalctl -u xboard-audit -f
```

重启网络审计服务：

```bash
systemctl restart xboard-audit
```

停止网络审计服务:

```bash
systemctl stop xboard-audit
```

## **手动安装**

### 创建python虚拟环境

```bash
python3 -m venv xboard_env
```

### 在虚拟环境中安装电报依赖库:

```bash
/root/xboard_log/xboard_env/bin/pip install --upgrade pip
/root/xboard_log/xboard_env/bin/pip install python-telegram-bot
```

### 将xboard-node日志写入/root/xboard_log/xboard.log

```bash
nohup journalctl -u xboard-node -f --no-pager > /root/xboard_log/xboard.log 2>&1 &
```

### 刷新服务配置

```bash
systemctl daemon-reload
```

### 开启开机自启并现在启动

```bash
systemctl enable --now xboard-audit
```

### 查看运行状态是否为 active (running)

```bash
systemctl status xboard-audit
```

### 实时查看报错/运行日志

```bash
journalctl -u xboard-audit -f
```

### 重启监控服务

```bash
systemctl restart xboard-audit
```

### 停止监控服务

```bash
systemctl stop xboard-audit
```
