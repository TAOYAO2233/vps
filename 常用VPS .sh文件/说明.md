# VPS Shell 脚本说明

本目录中的脚本相互独立。先打开脚本检查顶部配置、系统路径和会执行的命令，再在对应的 Linux VPS 上运行。多数脚本面向 Bash，部分需要 root、FFmpeg、ffprobe、yt-dlp、tdl 或 curl。

## 系统维护 `system/`

| 脚本 | 作用与注意事项 |
| --- | --- |
| [`sshkey_manager.sh`](system/sshkey_manager.sh) | 交互管理 SSH 公钥、登录方式与端口；修改 `sshd_config`、防火墙或 SELinux 前保留现有 SSH 会话，测试新连接后再退出。 |
| [`lscolorsetup.sh`](system/lscolorsetup.sh) | 为 Bash/Zsh 写入 `ls` 配色与别名；支持卸载选项，会备份配置文件。 |
| [`linuxcheck.sh`](system/linuxcheck.sh) | 输出系统安全与运行信息供人工排查；阅读输出后再决定处置。 |
| [`monitor_xrayr.sh`](system/monitor_xrayr.sh) | 监听 XrayR 访问日志，按时间窗口发送 Telegram 通知；先填写脚本顶部的 Token、Chat ID 和日志路径。 |

## 媒体 `media/`

| 脚本 | 作用与注意事项 |
| --- | --- |
| [`viedo_master.sh`](media/viedo_master.sh) | 交互选择视频进行合并、转换或删除；文件名中的 `viedo` 是现有名称。 |
| [`stream_videos_with_interval.sh`](media/stream_videos_with_interval.sh) | 选择视频并向 RTMP 地址轮播推流；配置、缓存写在用户主目录，日志目录默认为 `/var/log/stream_logs/`。 |
| [`convert_flv_copy_mp4.sh`](media/convert_flv_copy_mp4.sh) | 用 FFmpeg `-c copy` 将 FLV 重封装为 MP4；先修改固定的 `SOURCE_DIR`、`LOG_FILE` 和 `MAX_JOBS`。源编码必须适合 MP4 容器。 |
| [`convert_flv_to_mp4.sh`](media/convert_flv_to_mp4.sh) | 将 FLV 重编码为 MP4；先修改固定目录和并发数，运行会占用 CPU。 |
| [`download_video.sh`](media/download_video.sh) | 交互式调用 yt-dlp，支持选择格式与记住下载目录；需要 yt-dlp，合并视频与音频时需要 FFmpeg。 |
| [`delete_old_files.sh`](media/delete_old_files.sh) | 按脚本中的目录、时间和关键词规则直接删除文件；务必先审查 `TARGET_DIRS` 与 `KEYWORDS`，在副本上试运行。 |

## 网络 `network/`

| 脚本 | 作用与注意事项 |
| --- | --- |
| [`tdl_commands.sh`](network/tdl_commands.sh) | 调用 tdl 导出 Telegram 消息和媒体；先检查脚本中使用的路径和时间范围。 |
| [`tdl_forward_commands.sh`](network/tdl_forward_commands.sh) | 读取本地导出文件并用 tdl 转发；先核对源目录及接收会话。 |
| [`v2bx/install.sh`](network/v2bx/install.sh) | 安装和管理 V2bX 服务；会更改系统服务及相关文件，仅在目标主机确认配置后运行。 |

## 运行示例

```bash
cd '常用VPS .sh文件'
bash system/linuxcheck.sh
```

需要定时执行的脚本，先手动运行并检查日志，再加入 systemd timer 或 cron。不要把包含 Token 的脚本或运行日志公开。
