## 🛡️ 一、系统安全与运维审计 (`system/`)

### 1. `sshkey_manager.sh`
* **功能概述**：全功能交互式 SSH 安全管理脚本，告别手动改配置导致的断连失联风险。
* **核心亮点**：
  * **密钥管理**：支持生成高安全性 Ed25519 密钥对（防误覆盖），或从 GitHub / 外部 URL 一键拉取公钥。
  * **安全校验**：公钥写入前通过 `ssh-keygen -l` 严格校验格式，去重基于 Base64 特征码比对。
  * **防失联机制**：修改端口或关闭密码登录前，**强制执行 `sshd -t` 语法检测**，语法错误自动秒级回滚原文件并阻止重启服务。
  * **防火墙与 SELinux 联动**：修改端口自动放行 UFW / Firewalld，并在开启 SELinux 的系统上自动更新 `semanage` 策略。
  * **安全提示**：修改端口后高亮提醒云厂商控制台（阿里云/腾讯云/AWS/甲骨文等）安全组规则。
  * **删除公钥**：提供编号交互式删除指定已授信公钥。
* **运行命令**：
  ```bash
  bash system/sshkey_manager.sh
  ```

### 2. `lscolorsetup.sh`
* **功能概述**：终端彩色高亮与常用别名增强脚本。
* **核心亮点**：
  * **多 Shell 支持**：根据 `$SHELL` 自动适配并写入 `~/.bashrc` 或 `~/.zshrc`。
  * **视觉优化**：目录明亮蓝色、可执行文件高亮绿色，普通文件继承终端默认前景色（完美适配深色与浅色背景主题）。
  * **实用别名**：内置 `ls`、`ll` (`ls -lh`)、`la`、`lla` (`ls -lah`)，默认启用 `--group-directories-first`（目录排在最前）。
  * **安全退出与卸载**：首次写入前自动备份，支持 `--uninstall` / `-u` 一键还原原配置。
* **运行命令**：
  ```bash
  # 直接执行
  bash system/lscolorsetup.sh
  # 或通过 source 立即生效
  source system/lscolorsetup.sh
  ```

### 3. `linuxcheck.sh`
* **功能概述**：Linux 应急响应与安全基线体检脚本。
* **核心检查项**：
  * 检测核心命令（如 `/bin/ps` 等）近期是否被篡改。
  * 查看当前网络连接、对外监听端口以及高危端口。
  * 检查自启动项、Crontab 定时任务、Systemd 服务。
  * 识别 CPU 异常消耗进程、特权用户 (UID=0) 与近期修改的可疑文件/脚本。
  * 检查结果与日志自动打包保存于 `/tmp/` 目录供分析。
* **运行命令**：
  ```bash
  sudo bash system/linuxcheck.sh
  ```

### 4. `monitor_xrayr.sh`
* **功能概述**：XrayR 访问日志实时审计与 Telegram 告警推送工具。
* **核心亮点**：
  * **低资源损耗**：采用纯 Bash 行缓冲拆分解析，无需每行唤醒 `awk` 进程。
  * **防告警风暴**：内置时间窗口聚合机制（默认 10 秒批处理），将访问日志打包合并为一条 HTML 消息发送到 Telegram。
* **前置准备**：编辑脚本开头填入 `TG_BOT_TOKEN`、`TG_CHAT_ID` 与 `LOG_FILE` 路径。
* **运行命令**：
  ```bash
  nohup bash system/monitor_xrayr.sh > /dev/null 2>&1 &
  ```

## 🎬 二、视频与多媒体自动化处理 (`media/`)

### 1. `viedo_master.sh`
* **功能概述**：交互式多媒体处理大师（Video Master Tool v8.0）。
* **核心亮点**：
  * **多段视频拼接**：智能提取视频片段日期并重命名，自动剔除冗余时间戳，通过 FFmpeg Concat 无缝合并多段录播。
  * **格式转换与修复**：支持常见格式（FLV / MKV / TS / MOV / AVI）转换为标准 MP4，修复时间戳紊乱问题。
  * **工作区记忆**：自动记忆上次处理的目录路径。
* **前置依赖**：`ffmpeg`
* **运行命令**：
  ```bash
  bash media/viedo_master.sh
  ```

### 2. `stream_videos_with_interval.sh`
* **功能概述**：全自动 RTMP 直播推流脚本（支持无人值守与轮播）。
* **核心亮点**：
  * **终端分页选择**：支持一页 10 个视频浏览与勾选。
  * **元数据缓存加速**：自动缓存视频时长与体积，二次加载毫秒级响应。
  * **间隔推流与循环**：支持在视频之间配置等待间隔（默认 10 秒），支持 `LOOP=true` 无限循环推流至直播间。
* **前置依赖**：`ffmpeg`
* **运行命令**：
  ```bash
  bash media/stream_videos_with_interval.sh
  ```

### 3. `convert_flv_copy_mp4.sh`
* **功能概述**：高并发极速流复制无损转换脚本（适合录播姬等工具录制的标准 FLV）。
* **核心亮点**：
  * 采用 `ffmpeg -c copy` 极速重新封装，仅进行解包和重新封装，**不占用 CPU 算力**，几秒即可处理数 GB 视频。
  * 内置最大并发控制（`MAX_JOBS=5`），排队异步执行。
  * 转换成功后自动清理原 `.flv` 文件，并详细记录 `conversion.log`。
* **运行命令**：
  ```bash
  # 可根据实际情况修改脚本内的 SOURCE_DIR 与 LOG_FILE
  bash media/convert_flv_copy_mp4.sh
  ```

### 4. `convert_flv_to_mp4.sh`
* **功能概述**：深度重编码转换脚本（针对音画不同步或损坏的 FLV 流）。
* **核心亮点**：
  * 采用 `libx264` + `aac` 全量重编码修复。
  * 引入 `nice -n 10` 降低进程调度优先级，限制 `MAX_JOBS=2`，避免高负载跑死 VPS。
  * **完整性校验**：转换后使用 `[ -s "$mp4_file" ]` 确保非空才删除源文件，失败时自动清理残余文件。
* **运行命令**：
  ```bash
  bash media/convert_flv_to_mp4.sh
  ```

### 5. `download_video.sh`
* **功能概述**：基于 `yt-dlp` 的终端增强下载器。
* **核心亮点**：
  * 启动自动联网检测最新 GitHub 版本，支持一键升级二进制文件。
  * 智能调用 `-F` 列出全部分辨率与音频轨道代码供选择，回车默认下载最佳音画合并版本。
  * 支持自定义下载路径管理（历史路径添加、保存、删除）。
* **前置依赖**：`yt-dlp`, `ffmpeg`
* **运行命令**：
  ```bash
  bash media/download_video.sh
  ```

### 6. `delete_old_files.sh`
* **功能概述**：VPS 磁盘自动清理与维护脚本。
* **核心亮点**：
  * 批量监控多个录播输出目录。
  * 自动搜索修改时间超过指定时间（如 1800 分钟 / 30 小时）的文件并清理。
  * 支持指定自定义关键词过滤批量清理。
* **运行命令**：
  ```bash
  # 适合配置在 crontab 定时任务中（例如每天凌晨 4 点运行）
  bash media/delete_old_files.sh
  ```

## 📲 三、Telegram 数据与网络代理工具 (`network/`)

### 1. `tdl_commands.sh`
* **功能概述**：利用 TDL 命令行工具导出 Telegram 频道/群组的聊天历史与多媒体。
* **核心亮点**：
  * 支持三种导出模式：默认时间跨度、自定义起始与截止时间戳、全量导出。
  * **按时段自动分卷**：按时间窗口（默认两个月）自动分片导出为 `tdl-export1.json`, `tdl-export2.json` 等，避免一次性导出超大文件发生网络中断或内存溢出。
* **前置依赖**：已登录配置好环境的 `tdl` 命令行工具。
* **运行命令**：
  ```bash
  bash network/tdl_commands.sh
  ```

### 2. `tdl_forward_commands.sh`
* **功能概述**：TDL 分卷导出数据批量自动转发工具。
* **核心亮点**：
  * 自动递增序号遍历已导出的 `tdl-export*.json` 分片文件。
  * 自动化调用 `tdl forward` 批量推送到指定个人会话或收藏夹。
  * 带有速率延迟控制（`--delay 5s`），转发成功后自动删除本地已处理切片，并记录详细成功/失败日志。
* **运行命令**：
  ```bash
  bash network/tdl_forward_commands.sh
  ```

### 3. `v2bx/install.sh`
* **功能概述**：V2bX 多协议代理节点服务一键管理脚本。
* **核心亮点**：
  * 自动识别操作系统发行版（CentOS / Debian / Ubuntu / Alpine / Arch 等）与 CPU 架构（x86_64, aarch64 等）。
  * 自动化拉取最新 release、配置 systemd 服务守护与开机自启。
* **运行命令**：
  ```bash
  sudo bash network/v2bx/install.sh
  ```

## 💡 使用小贴士

1. **执行权限**：拉取到 Linux VPS 后，若提示权限不足，可为指定分类一键赋予执行权限：
   ```bash
   chmod +x system/*.sh media/*.sh network/*.sh network/v2bx/*.sh
   ```
2. **文本换行符（CRLF vs LF）**：
   本仓库中所有 `.sh` 文件均统一采用标准 Unix LF 换行符。如在 Windows 环境下编辑，请确保编辑器（VSCode 等）保存为 LF，避免在 Linux 运行提示 `/bin/bash^M: bad interpreter`。
